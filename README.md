# Resume Tailor Local

[English](README.md) | [Deutsch](README.de.md) | [中文](README.zh.md)

Resume Tailor Local is a privacy-conscious desktop tool for tailoring resumes to job descriptions. It reads a resume, scores it against a pasted JD, optionally rewrites it with an LLM, and exports a tailored HTML resume and PDF.

The current focus is German and European-style resumes. The app can also switch the resume language between German and English based on the JD language.

## Features

- Read `.docx` resumes, including normal paragraphs and Word text boxes.
- Read HTML resumes generated by this tool and reuse them as a future Master Resume.
- Paste a JD and generate a match report.
- Combine rule-based scoring with optional LLM semantic scoring.
- Use OpenAI, DeepSeek, Ollama, or run fully in local rule-only mode.
- Rewrite the profile, skills, and experience bullets based on the JD.
- Apply basic factual guardrails to avoid unsupported claims such as invented projects, clients, certificates, or job titles.
- Generate German or English resume output based on the JD language.
- Export HTML/CSS and print to PDF through local Microsoft Edge or Google Chrome.
- Review changes, manually edit the tailored resume, preview HTML, and export PDF from the GUI.
- Cache LLM responses to reduce token usage during repeated tests.

## Requirements

- Windows 10/11
- Python 3.11 or newer
- Microsoft Edge or Google Chrome for HTML-to-PDF export
- Optional: OpenAI / DeepSeek API key, or local Ollama

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Start the GUI:

```bash
python gui.py
```

On Windows, you can also double-click:

```bat
start_gui.bat
```

`start_gui.bat` creates a local `.venv` and installs dependencies automatically. `.venv/` is ignored by Git.

## Quick Start

1. Click `填写/编辑简历` in the desktop app.
2. Replace the fictional Max Mustermann content in the editor and save it as `master_resume.html`.
3. Paste the job description into the JD text box.
4. Choose an LLM provider: `off`, `openai`, `deepseek`, or `ollama`.
5. Click `1. Analyze` to generate match scores.
6. Click `2. Generate Resume` to create a tailored HTML resume.
7. Click `3. Review & Edit` to inspect and manually adjust the result.
8. Click `4. Preview` to open the generated HTML.
9. Click `5. Export PDF` to create the final application file.

The GUI currently contains Chinese labels because the project started as a local personal workflow. Internationalization is a planned improvement.

## First-Time Users Without a Resume

The filled example template is:

```text
resume_templates/mustermann_resume_template.html
```

You do not need to edit this HTML file by hand. Click `填写/编辑简历` in the app to edit the template through a form-like interface.

## HTML as Master Resume

Recommended workflow:

```text
filled HTML resume -> new JD -> tailored HTML/PDF
```

The GUI is intentionally HTML-first. DOCX parsing still exists in the CLI, but the desktop workflow is designed around editable HTML templates.

## LLM Settings

When you enter an API key in the GUI and save the settings, the app stores them in:

```text
.config/settings.json
```

`.config/` is ignored by Git.

You can also configure the app through environment variables:

```bash
RESUME_TAILOR_LLM=deepseek
RESUME_TAILOR_MODEL=deepseek-v4-flash
DEEPSEEK_API_KEY=your_api_key
```

```bash
RESUME_TAILOR_LLM=openai
RESUME_TAILOR_MODEL=gpt-5.2
OPENAI_API_KEY=your_api_key
```

```bash
RESUME_TAILOR_LLM=ollama
RESUME_TAILOR_MODEL=llama3.1
OLLAMA_BASE_URL=http://localhost:11434
```

## LLM Cache

The app caches LLM responses to reduce repeated testing costs.

- Cache directory: `.cache/llm/`
- Cache key: provider, model name, system prompt, and user prompt
- Delete `.cache/llm/` to force a new LLM call

`.cache/` is ignored by Git.

## CLI Examples

```bash
python app.py analyze --resume "path/to/resume.docx" --jd jd.txt --out outputs/match_report.md
python app.py analyze --html outputs/tailored_lebenslauf.html --jd jd.txt --out outputs/match_report.md
python app.py tailor-html --resume "path/to/resume.docx" --jd jd.txt --template "path/to/template.docx" --out outputs/tailored_lebenslauf.html
python app.py export-pdf --html outputs/tailored_lebenslauf.html --out outputs/tailored_lebenslauf.pdf
```

## Privacy

This is a local tool. Resumes, JDs, and generated outputs are stored on your machine by default.

If OpenAI or DeepSeek is enabled, the app sends the JD and structured resume content to the selected API provider. If privacy is critical, use `off` mode, local Ollama, anonymized test data, and regular cleanup of `.config/`, `.cache/`, and `outputs/`.
